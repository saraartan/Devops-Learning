# 🌐 Cloud Web Server Deployment (AWS EC2 + NGINX + Domain)

In this project, I deployed a fully functional web server using AWS EC2. I configured an Ubuntu Linux instance, installed and managed NGINX, and connected a custom domain using Cloudflare DNS.

This project demonstrates core DevOps and cloud infrastructure skills, including virtual machine provisioning, web server setup, networking, and DNS configuration. It simulates a real-world deployment workflow used in production environments.
